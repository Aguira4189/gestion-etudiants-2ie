# 🎓 Application Gestion Étudiants 2iE

Application web de gestion des étudiants de l'Institut 2iE.

## Stack technique
- **Frontend** : React + Vite + TailwindCSS
- **Backend** : Express.js + MySQL2 + JWT
- **Base de données** : MySQL (Laragon)

## Installation

### Backend
```bash
cd backend/backeend
npm install
# Configurer le fichier .env
npm run dev
```

### Frontend
```bash
cd frontend-vite
npm install
npm run dev
```
